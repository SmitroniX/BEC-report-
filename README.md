# Spatial Horizons — Augmented & Virtual Reality in Next-Gen Tourism

An award-winning, cinematic spatial computing web experience exploring the transformative intersection of **Augmented Reality (AR)** and **Virtual Reality (VR)** in global tourism, cultural heritage preservation, and spatial computing architectures.

---

## 🌐 Live Access & Quick Start

The presentation web application is running locally on port **`8090`**:

👉 **`http://localhost:8090/`**

### Launching the Server
```bash
bash /home/ubuntu/xr_tourism_presentation_web/start_presentation.sh 8090
```
Or directly using Python:
```bash
python3 -m http.server 8090 --directory /home/ubuntu/xr_tourism_presentation_web
```

## 🎮 Interactive Controls & Dual Modes

- **Dual Mode Toggle**:
  - **Deck Mode (16:9 Presentation)**: Slide-by-slide full-screen presentation deck with animated card transitions.
  - **Scroll Mode (Continuous Page)**: Fluid, cinematic storytelling web page with sticky navigation tracking.
- **Keyboard Shortcuts**:
  - `→` / `Space` / `PageDown`: Next Slide
  - `←` / `PageUp`: Previous Slide
  - `1` – `9`, `0`: Jump directly to Slide 1 through 10
  - `O`: Toggle 10-Slide Visual Overview Matrix Modal
  - `S`: Toggle Web Audio API Synthesizer (Holographic chirps, whooshes, ambient drone)
  - `P`: Toggle Autoplay (automated slideshow progression)
  - `F`: Toggle Fullscreen Mode
  - `Esc`: Close open modal windows
- **Web Audio API Engine**:
  - Pure synthesized sound design with zero external MP3 dependencies.
  - Generates holographic button clicks, stage transition whooshes, and an ambient spatial drone.
